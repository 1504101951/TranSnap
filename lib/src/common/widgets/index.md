# lib/src/common/widgets目录索引

原生玻璃控件与系统拉伸光标等共享界面能力。

1. [index.md](index.md)：索引本目录直接子文件和子目录的用途。
2. [native_glass.dart](native_glass.dart)：实现共享原生玻璃材料、主题和界面控件。
3. [native_resize_cursor.dart](native_resize_cursor.dart)：通过截图通道为四角拉伸设置AppKit原生对角光标。
4. [toolbar_feedback.dart](toolbar_feedback.dart)：在工具栏外侧的可用区域显示保存、成功及错误响应。
5. [native_brush_cursor.dart](native_brush_cursor.dart)：通过截图通道设置与画笔粗细、颜色一致的原生圆点光标。
6. [app_motion.dart](app_motion.dart)：提供物理弹簧进场、舒缓链式入场、玻璃骨架扫光、光学棱镜着色器装饰层、纯 Dart 矢量状态机图标、等待进度环、译文逐字显影、选区流光与工具栏液态展开。
7. [result_window.dart](result_window.dart)：提供录制、长截图与打开图片共用的结果窗口衬底、媒体框、52pt 底部操作栏、按钮与向上展开属性托盘。
8. [window_drag_area.dart](window_drag_area.dart)：让通顶窗口标题栏带的空白处可以拖动原生窗口。
9. [line_icon.dart](line_icon.dart)：按显示尺寸选用 Lucide 字重，使各尺寸图标的屏幕线宽接近 1.6pt。
10. [app_tooltip.dart](app_tooltip.dart)：提供统一的悬浮气泡提示组件，支持在浮层窗口中经原生气泡突破窗口边界显示。

# 使用说明

安装位置固定为 `/Applications/TranslateApp.app`。菜单栏翻译图标提供设置、区域截图、翻译历史、仅使用快捷键开关和退出入口。

## 选区翻译

1. 在其他应用拖选、双击、三击，或用 ⌘A、Shift 配合方向/Home/End/Page 键选中文字，旁边出现「翻译」按钮。键盘选区暂时读不到文字时先显示待确认按钮，点击后才读取。文件和安全控件不显示按钮。
2. 点击按钮展开双栏卡片：左译文、右原文，各栏独立滚动，悬停译文段落高亮对应原文段落，两栏可分别复制全文；原文已是目标语言时只显示一栏原文。正文使用不透明阅读底色，不受「玻璃透明度」影响。按钮和卡片顶部标题区可拖动。各栏栏头的朗读按钮用系统离线语音朗读该栏全文，再次点击停止；关闭卡片或开始新翻译时自动停止。标题区的服务菜单可切换到任一已配置的翻译服务，用它重新处理当前原文，只影响这张卡片，下次翻译仍用默认服务。模式菜单可切换为「润色」「纠错」「解释」，对同一原文重新处理：润色与纠错保持原文语言，解释使用主要语言；这三种模式需要模型服务（OpenAI、DeepSeek 或 Anthropic），此时服务菜单只列模型服务，结果不写入翻译历史。三种模式的提示词在「设置 → 翻译 → 术语与提示词 → 编辑提示词…」统一修改，可分别恢复默认。
3. 全局快捷键 **⌃⌥T** 直接翻译当前选区。开启「仅使用快捷键」后不再自动显示按钮。
4. 输入翻译快捷键 **⌃⌥R** 翻译输入框中选中的文字，没有选中文字时翻译整个输入框；全程不显示译文卡片，读取原文后 300ms 仍未完成时在选中文字附近显示「翻译中…」浮标（点击穿透），完成后直接替换为译文，可用来源应用的 ⌘Z 撤销。翻译失败、来源应用已切换或处于密码输入时不替换，浮标原地换成失败原因，2.5 秒后消失，点击可立即关闭。替换经剪贴板完成，0.5 秒后还原原剪贴板。在只读内容（如 Claude 的回复）里选中时，译文写入窗口内唯一的输入框；微信等不提供辅助功能信息的应用只支持在输入框内选中。
5. 自动检测只读辅助功能；点击翻译或用快捷键时允许一次性复制读取，保留网页段落与换行，并恢复剪贴板。读取为空时显示失败卡片，不发送旧选区。
6. 语言在设备上识别：设置次要语言时，主要语言译为次要语言，其余译为主要语言；未设置时统一译为主要语言，已是主要语言的文本直接展示、不发请求。输入翻译使用单独的一组主要/次要语言：在「设置 → 翻译 → 翻译语言」右上角切到「输入翻译」后设置，未设置过时与全局翻译相同；划词、全局翻译快捷键、截图文字翻译与实时翻译使用「全局翻译」一组。单次上限 50,000 字符。
7. 小按钮随选区清空、外部点击、切换应用或新选区消失；展开后的卡片通过 Esc 或 × 关闭，删除卡片正在使用的服务也会关闭并取消翻译。下一次翻译使用设置中的默认服务，删除默认服务后使用内置服务。快捷键翻译会替换为新内容。

## 词典与生词本

1. 选中 1–3 个英文单词（不超过 40 个字符）或 1–4 个汉字翻译时，同时用 macOS「词典」App 已启用的词典离线查询；查到时卡片右侧 3/5 为「词典」释义，词条与音标、词性、义项、例句各自分行；左侧 2/5 上为译文、下为原文，字号加大；词典栏朗读按钮读出原词。
2. 词典栏栏头的「加入生词本」把单词、译文与释义保存到本地；同一单词再次加入会更新内容。
3. 菜单栏「翻译历史」窗口顶部可切换「生词本」：按加入时间倒序查看、删除，底部「导出 CSV」经保存面板导出（UTF-8、无表头，列为单词、译文、释义），可直接导入 Anki。

## 术语表

1. 「设置 → 翻译 → 语言与服务」的「术语与提示词」行点击「管理术语」，在弹窗中「添加术语」填写原文术语、译法与目标语言（默认主要语言），也可编辑或删除已有术语；译法留空表示保留原文不译。同一目标语言下同一术语（不区分大小写）只能有一条，改动自动保存。
2. 术语表只对模型服务（OpenAI、DeepSeek、Anthropic）的翻译生效，覆盖选区、输入、截图与实时翻译；谷歌、百度与 Apple 系统翻译的接口不支持按请求传入术语，润色、纠错、解释也不使用术语表。
3. 每次翻译只把原文中出现、且目标语言一致的术语发给模型；英文等术语按整词匹配，`API` 不会命中 `capital`。
4. 「导入…」支持 UTF-8 CSV 与 JSON：CSV 表头为 `term,translation,language`，JSON 为含这三个字符串字段的对象数组。译法可为空；语言使用语言标签，如 `zh-CN`、`en`。
5. 导入预览列出新增、重复和错误行；重复项默认保留已有值，可选择覆盖。文件内重复同样按文件顺序处理。存在无效行时整批不保存；取消不改变设置，保存失败保留预览和错误。「导出…」只导出术语，不包含服务或凭据。

## 截图

1. 菜单栏「区域截图…」或 **⌃⌥S** 冻结当前画面后框选，Esc 取消。首次使用按提示授予屏幕录制权限，系统要求时重开 App。
2. 工具栏优先放在选区下方，其次上方、右侧、左侧；空白不足时放进选区内侧。拖动选区时工具栏隐藏。
3. 非文字输入状态按回车或双击执行「设置 → 截图 → 操作 → 回车或双击确认时」的动作并退出：复制图片（默认）或复制并保存；失败时保留编辑。
4. 保存写入「截图目录/截图/YYYY-MM-DD」，默认根目录为 `~/Pictures/截图`；文件名含日期、时间和毫秒，重名追加序号。「复制并保存」先保存再复制，保存失败不改剪贴板。操作结果提示显示 1 秒。
5. 截图只保存在本地；只有点击「识别文字」「翻译文字」才识别或发送文字。
6. 菜单栏还提供「截取显示器」：冻结所选显示器并选中整屏。
7. 菜单栏「打开图片…」和「从剪贴板打开图片」把图片送入同一编辑器；支持系统可解码格式，动图使用首帧，源文件保持只读。图片可标注、复制、保存、识别、翻译和贴图，不需要屏幕录制权限，不能从图片启动录屏、滚动长截图或实时翻译。识别在设备执行，只有显式翻译才发送文字。
8. 关闭或替换截图、图片会取消进行中的翻译与网络请求，停止后续分片；过期结果不显示，也不写翻译历史。
7. 「设置 → 截图 → 录制 → 截图包含鼠标指针」默认关闭；打开后冻结画面包含鼠标指针，MCP 截图不受影响。

### 框选精确控制

- 「截图」或「光标」工具下，选区左上角外侧显示像素尺寸「宽 × 高」，选区贴近顶部时显示在选区内。
- 没有文字输入且没有选中标注时：方向键移动选区 1 像素，⇧ 为 10 像素；⌥+方向键以左上角为锚点调整宽高（→/↓ 增大，←/↑ 减小），⌥⇧ 为 10 像素。选区不越出截图，最小边长 8 像素。
- 工具栏「比例」展开比例行：自由、1:1、4:3、3:4、16:9、9:16。选择后选区以左上角为锚点保持宽度调整高度，超出截图则整体缩小；之后新框选、拖动控制点与 ⌥+方向键都保持比例。每次截图默认「自由」。

### 标注

- 图形：矩形框、圆形框、矩形填充、圆形填充；另有箭头、画笔、马赛克画笔（12 像素网格）与荧光笔。线宽 1–20pt，默认 3pt。调色盘分「纯色」「渐变」两页：渐变可选 6 种预设，或自定义起始色、结束色与方向（→ ↓ ↘ ↗）；图形、箭头、画笔、荧光笔、文字与编号都可用渐变（马赛克无颜色）。每种工具分别记住自己的颜色（含渐变）、粗细与模式，重启后保留。
- 荧光笔：画笔第二行选择「荧光笔」，默认黄色、16pt，以 40% 不透明度覆盖，下方文字仍清晰；同一笔来回涂抹不加深。
- 编号：选择「编号」后单击放置 1、2、3… 的圆形标记，按住拖动可调整位置后松开；可连续快速单击。编号按放置顺序排列，撤销或重做后自动重新编号；颜色可调，数字按底色自动取黑或白。
- 光标工具选中已有标注后可修改样式。画笔使用与粗细、颜色一致的圆点光标。
- 文字：点击放置文字框，回车换行；点击框外、Esc 或切换工具结束输入；空文字框自动删除；单击选中、再次点击进入编辑；拖动只改宽度，高度随内容。
- ⌘Z 撤销，⇧⌘Z 重做。

### 美化

- 工具栏「美化」展开美化行：「背景」按钮打开调色盘选择纯色或渐变（默认渐变「晨曦」），调色盘里可勾选「阴影」或点「无背景」关闭美化；「内边距」下拉为 32/64/96pt，「圆角」下拉为直角或圆角（12pt）。选择背景后，选区四周直接显示导出效果。
- 贴纸：「美化」展开后第二行的「贴纸」打开贴纸下拉框，顶部分「Emoji」（默认）与「贴纸」两段：点选表情或「我的贴纸」即放到选区中央并收起；两段底部的「管理贴纸…」结束本次截图并打开设置窗口。用光标工具拖动贴纸移动，拖八个控制点缩放（按住 ⇧ 保持比例），拖上方圆形手柄旋转（按住 ⇧ 按 15° 吸附），按 Delete 删除；开启美化时贴纸可以拖到背景留白区。「设置 → 截图 → 贴纸」管理我的贴纸：「添加图片…」选择图片后在上传框拖动四角设定默认大小，悬停缩略图可删除。
- 复制、保存与回车复制输出美化后的图片；贴图、识别文字与翻译文字使用原图。每次截图默认不美化，在背景调色盘点「无背景」即关闭。

### 取色与标尺

- 「截图」的子级行有「取色」与「标尺」。取色：指针处显示色块与 `#RRGGBB`（截图源像素），单击复制该色值。标尺：拖动画出测量线，终点旁显示「长度 px（Δx × Δy）」，单位为截图像素。
- 测量线与取色标签不出现在复制、保存或贴图的图片中，也不进入撤销；新拖动替换上一条，切换工具或新截图后清除。

### 识别、翻译与贴图

- 「识别文字」：在本机同时识别文字与二维码/条码，打开「识别结果」弹窗，按 Markdown 渲染标题、段落、列表与表格（宽表格可横向滚动），可选中部分复制；「复制全部」复制 Markdown 原文，弹窗不自动关闭。
- 识别到二维码或条码时，正文顶部逐条列出类型与完整内容，「复制内容」复制该条；内容是 http/https 链接时可点「打开链接」用默认浏览器打开并关闭截图，其他内容只能复制。既无文字也无码时提示「画面中没有可识别的文字、二维码或条码」。
- 「翻译文字」：按段落识别后用当前翻译服务分批翻译，每段译文到达即逐字显影盖在该段原位；未完成或失败的段落保留原图，工具栏显示翻译状态；某段的语言对不受支持或缺少语言包时只放弃该段，失败原因一直显示到下一条提示。结果不写入翻译历史。
- 识别、翻译、复制、保存、贴图与开始录制等等待期间，被点击的按钮外圈出现强调色进度环，完成时闭合淡出；按钮被隐藏或由回车等触发时，进度环出现在工具栏末尾。
- 截图选区边框带一段强调色流光，拖动或调整选区时加速，选区定下后再流两圈淡出。点开截图、图形、美化等父级时，子级按钮从父级按钮处液态分裂弹出，收起时融合回父级。
- 「贴图」：把截图钉在屏幕最上层，不抢当前应用焦点；单击拖动，滚轮或捏合缩放，双击或 Esc 关闭。

### 截图历史

- 菜单栏「翻译历史」窗口顶部切换到「截图历史」，开启「记录截图历史」（默认关闭）后，复制、保存或贴图成功的截图另存一份到 App 自己的历史目录；同一次截图多次导出只保留最后一次的图片。
- 最多保留 100 张、30 天内的截图，超出时删除最早的记录及其图片；保存到截图目录的文件不受影响。
- 每条显示缩略图、截图时间与像素尺寸，可打开、复制图片、在 Finder 中显示或删除；图片被移走时显示「图片文件已缺失」，只能删除。「清空截图历史」删除全部记录与历史图片。
- 勾选卡片左侧的方框后可处理多张截图：「拼接」（至少 2 张，纵向或横向，按截图时间先后排列，不缩放，尺寸不同时居中、空白透明）；「拆分」（1 张，按高度等分为 2–10 段，余数并入最后一段）；「比较」（2 张，并排显示，可高亮像素差异并显示差异像素占比）。拼接与拆分的结果作为新记录加入截图历史，不受「记录截图历史」开关限制。

## 录屏、GIF/APNG/WebM 与滚动长截图

1. 工具栏「截图」下的「录制」可选区域、窗口、全屏目标；窗口目标按应用列出，截图前的当前应用优先。视频为 30fps、无音轨 MP4。
   - 「开始录制」左侧的「录制选项」可选「不延时」（默认）或延时 3、5、10 秒，以及「显示鼠标点击」；选择即保存，下次截图保留。延时时点「开始录制」后先撤下冻结画面倒计时，期间可正常操作其他应用，悬浮条显示「n 秒后开始」，菜单栏图标显示剩余秒数，倒计时画面不进入视频。倒计时中点悬浮条「放弃」或菜单栏「停止采集」回到截图编辑并保留选区与标注；倒计时中发起新截图则放弃倒计时。滚动长截图与实时翻译不延时。
2. 「滚动长截图」框选后立即开始，默认手动向下滚动来源应用；相邻画面需有足够重叠，顶部与底部固定区域自动去重，无法可靠拼接时停止并保留已确认部分。
   - 「设置 → 截图 → 操作 → 长截图滚动方式」选「自动滚动」后，App 自动向下滚动选区里的内容，不移动指针；到底自动暂停并提示「已到底部，已暂停」，点「结束」完成，点「继续」恢复自动滚动。
   - 自动滚动中在选区内滚动滚轮或触控板即改为手动（提示「已切换为手动滚动」）；在选区外滚动或移动鼠标不受影响。暂停按钮暂停，「继续」恢复自动滚动。
   - 自动滚动需要辅助功能权限。来源窗口有可调整的滚动条时直接调整；否则（如 Brave）向来源应用发送方向键，滚动时指针不动，鼠标可随意移动；焦点在网页输入框时滚不动，请先点一下网页正文。滚动不动时提示并改为手动滚动。
3. 采集期间使用悬浮条：暂停／继续、结束、放弃。暂停时间不计入视频；放弃立即清理临时文件。
4. 视频结果窗口可播放、裁剪、保存 MP4、导出 GIF、导出 APNG、导出 WebM；长图结果窗口可滚动查看、保存、复制或放弃。GIF 与 APNG 共用「设置 → 截图」中的帧率（1–30fps，默认 10）与最大宽度（默认不限），只缩小不放大，循环播放。WebM 为 VP8 编码、无音轨，保持原分辨率与原帧时间，不使用 GIF 设置，可在浏览器中播放；由系统 WebKit 编码，本机不支持 VP8 编码或编码器丢帧时提示失败且不保存。
5. 「裁剪」让播放器显示系统裁剪条：拖动首尾手柄后点「裁剪」确认，点「取消」保持原来的区间，可再次进入调整。确认后播放、保存 MP4、导出 GIF、APNG 与 WebM 都只使用所选区间；裁剪后保存 MP4 会重新编码，转换中可取消。源录制不改写，关闭结果窗口后裁剪不保留。
6. 「设置 → 截图 → 录制 → 录制时显示鼠标点击」（与「录制选项 → 显示鼠标点击」为同一设置）默认关闭；打开后区域与全屏录制在点击处显示系统点击高亮。窗口（应用）录制不含鼠标指针，不显示点击。
7. 保存位置：MP4 到「截图目录/视频/日期」，GIF 到「截图目录/gif/日期」，APNG 到「截图目录/apng/日期」（扩展名为 .png），WebM 到「截图目录/webm/日期」，长图到「截图目录/截图/日期」。

## 实时翻译

1. 截图工具栏的「实时翻译」选择区域、窗口或全屏目标后开始；译文按段落盖在原文位置，画面变化时持续更新。
2. 已翻译过的段落直接复用，不重复请求；网络波动自动重试，请求过于频繁时按服务要求的时间（最长 60 秒，未给出时依次 2、4、8 秒）等待后重试，同一段最多重试 3 次；密钥错误或额度不足立即停止并提示。
3. 悬浮条可暂停、结束、放弃。
4. 开启「设置 → 截图 → 录制 → 实时翻译时同时录制」后同步录制，画面包含译文，结束后进入录制结果窗口，可导出 GIF。

## 截图工具栏

「设置 → 截图 → 工具栏」是一张网格：每一行对应一种修饰键组合，每行 6 格，从左到右对应数字键 1–6，工具放在哪一格，快捷键就是「该组组合 + 格序号」（例如 ⌘ 组第 2 格为 ⌘2）。快捷键只在截图编辑中生效；网格顶部标出 1–6，每行左侧是组合，格子里只显示图标和名称。截图编辑时，工具栏在选区上方或下方（以及放进选区内）横放，每组 6 个按钮从左到右，两组并排为一行、左组靠左右组靠右；在选区左右两侧竖放时，每组 6 个按钮自上而下，两组上下为一列。可用长度放不下两组并排时每行一组。每组左侧标出组合（无修饰写「无」），按钮上不再标注键位，悬停提示显示名称和快捷键；点开截图、图形、美化等工具时，子级与属性作为新的一行（竖放时一列）插在它所在行后面，录制目标、窗口应用、比例与美化参数行也插在这里。

1. 默认 3 组：无修饰、⌘、⌥，16 个一级工具依次填为 6+6+4。每行左侧的下拉可改组合（无、⌘、⌥、⌃、⌘⌥、⌘⌃、⌥⌃、⌘⌥⌃，各组不重复，不能用 ⇧）；「添加组」最多 8 组，空组可删除。拖动组合下方的手柄可调整组的上下顺序（聚焦后也可用上下方向键），组合和工具随组移动，快捷键不变。
2. 把格子拖到任意格即得到该格快捷键，拖到有工具的格子会两者交换；点一下格子聚焦后用方向键与相邻格交换（左右在组内，上下跨组）。
3. 点按可承载子级的工具（如截图、图形、美化）在网格下方显示它的子级：把工具拖进来成为子级，把子级拖到格子成为一级。子级没有快捷键；默认「截图」下挂「录制」「滚动长截图」「取色」「标尺」，「美化」下挂「贴纸」。
4. 眼睛按钮隐藏工具时保留格位和快捷键，隐藏的工具仍可用快捷键调用。
5. 全局翻译、输入翻译、区域截图快捷键用到的格位标注「已用于…」，不能放工具；两边设置成同一组合时保存失败并说明原因。格位与已启用的系统快捷键相同时格子标红、显示「系统优先」，按下时由系统处理。

## 翻译历史

1. 菜单栏「翻译历史」打开独立窗口。卡片显示来源应用（或「截图」）、完成日期、完整译文与原文，可选中复制。每批 10 条，滚动加载，「刷新历史」回到最新。
2. 完整成功的选区翻译与截图文字翻译各自记录；失败、取消或未完成的不记录。
3. 「记录历史」默认开启，关闭后只停止新记录。记录不含选区坐标、截图图片或凭据。
4. 支持原文/译文关键词、来源和本地日期范围组合筛选；改变条件回到首批。刷新失败重试首批，分页失败重试当前页，失败时保留可见内容。
5. 单条删除需确认；「清空全部」会清除全部翻译历史，不受当前筛选影响，并在执行前确认。
6. 默认保留 30 天，可选 90 天、365 天或永久保留。选择有限期限会显示待清理数量并确认；首次对已有过期历史应用默认期限同样先确认。确认后自动按完成时间清理，取消不改设置或数据。保留期限不影响生词本、截图历史和保存的文件。

## 设置

1. 外观：浅色、深色、跟随系统；玻璃透明度 0%–80%（默认 20%）。系统开启减少透明度或增强对比度时使用不透明材料。选中、焦点等强调色跟随「系统设置 → 外观 → 强调色」，修改后各窗口即时更新；系统开启减少动态效果时动效改为直接显示。
2. 设置窗口左侧为两级导航：「通用」（外观；权限卡片含辅助功能、屏幕录制与 Apple 离线翻译语言包；登录启动在最下方）；「翻译」下有「语言与服务」「服务列表」「快捷键」「排除应用」；「截图」下有「保存与导出」「录制」「操作」「贴纸」「工具栏」；「MCP」。服务列表、排除应用、贴纸、工具栏条目多时在该页内滚动。
3. 排除应用中不读取选区：自动划词、全局翻译快捷键与输入翻译快捷键都不生效；截图、实时翻译与 MCP 截图不受影响。MCP 操控电脑不读取、不操作排除应用。
4. 快捷键点击后录制实际按键，Esc 或失焦取消；与系统或其他应用独占的组合冲突时保留原组合。macOS 无法枚举其他应用的内部快捷键。
5. 修改自动保存；失败时保留草稿并提示重试。
6. 「MCP」页：「允许 agent 截图」开启后本机 MCP 客户端可列出显示器与窗口、截图和识别文字。「允许操控电脑」默认关闭，只有在「允许 agent 截图」开启时才能打开；打开后客户端另可用无障碍 `snapshot`、`find` 读取应用界面元素，并用 `click`、`type_text`、`press_key`、`scroll`、`drag` 操作。模型首次操作某个应用时弹出授权面板，「本次会话允许」后该应用在本次会话内不再询问，30 秒无回应按拒绝。操控期间屏幕四边显示橙色边框，菜单栏首项为「停止操控」；按 Esc 或点「停止操控」立即结束，会话最长 30 分钟、5 分钟无操作自动结束，结束后再次操作需重新授权。模型不能向密码框输入，也不能发送退出、注销、锁屏与强制退出快捷键。操作记录在 `~/Library/Application Support/TranslateApp/control.log`，不含输入的文字。切换后需在 MCP 客户端重新连接才能看到新的工具列表。本应用、系统设置、钥匙串访问、密码、1Password、Bitwarden 与排除应用不可读取或操作。

## 翻译服务

谷歌翻译（零配置）与 Apple 系统翻译为内置服务，直接在「设置 → 翻译 → 语言与服务 → 默认翻译服务」选择。其他服务在「设置 → 翻译 → 服务列表 → 添加服务」填写配置，「测试连接」只发送 `Hello world.`，「确定」保存，再选择默认服务。支持多个命名配置；翻译失败不会自动换用其他服务。

| 服务 | 必填项 | 默认 API Base URL |
|---|---|---|
| Google 免费接口（非官方，初始默认） | 无 | 内置消费端接口 |
| 百度通用翻译 | App ID、密钥 | `https://fanyi-api.baidu.com` |
| 谷歌翻译（Cloud Translation Basic v2） | 已启用 Translation API 的项目 API Key | `https://translation.googleapis.com` |
| OpenAI | API Key、模型 ID | `https://api.openai.com/v1` |
| DeepSeek | API Key、模型 ID，思考由各模式开关控制，默认关闭 | `https://api.deepseek.com` |
| Anthropic 原生 Messages | API Key、模型 ID | `https://api.anthropic.com/v1` |
| Apple 系统翻译（内置） | 无 | 无，本机离线翻译 |

1. Base URL 不含接口路径或密钥；远程服务需要 HTTPS，本机 `localhost`、`127.0.0.1`、`::1` 可用 HTTP。可用性取决于服务商账户、网络和额度；消费端会员不等于 API 凭据。
2. API Key 与百度 App ID 只存在 Keychain。编辑时不显示已存密钥，留空即保留；删除服务会删除凭据。只有翻译、测试连接和修改凭据时才访问钥匙串。OpenAI、DeepSeek、Anthropic 等模型服务的 API Key 可留空（如不校验密钥的本机服务），留空时请求不带认证头；谷歌翻译与百度翻译仍须填写。
3. Apple 系统翻译使用 macOS 本机翻译模型，不联网、不保存凭据。语言包需先在「系统设置 → 通用 → 语言与地区 → 翻译语言」下载，「设置 → 通用」权限卡片中「安装 Apple 离线翻译语言包」一行的「下载翻译包」可直接打开该页面，同一行在打开通用页时列出主要语言与次要语言双向的安装状态；缺少时失败卡片写明缺少的语言对。原文语言无法识别或语言对不受支持（如简体与繁体中文互译）时直接提示。
4. 「设置 → 翻译 → 语言与服务 → 编辑提示词…」统一编辑翻译、润色、纠错、解释四套提示词，全部模型服务共用，每套可单独开关「思考」（默认关闭，只对 DeepSeek 与 Anthropic 生效）。开启「按段落双语对照」后，模型按编号返回每段译文，编号缺失、乱序或为空都报失败。
5. 长文按约 4,000 字分片；失败卡片保留已完成部分，「重试」从失败片继续，全部成功才写入历史。

接口参考：[百度通用翻译](https://fanyi-api.baidu.com/doc/21)、[Google Cloud v2](https://cloud.google.com/translate/docs/reference/rest/v2/translate)、[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode)、[Anthropic Messages](https://platform.claude.com/docs/en/api/messages)、[Apple Translation](https://developer.apple.com/documentation/translation/translationsession)。

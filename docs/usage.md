# TranSnap 使用指南

> 当前版本专注于 **macOS 26+（Darwin 25+）**。默认安装路径固定为 `/Applications/TranSnap.app`，菜单栏翻译图标提供设置、区域截图、翻译历史、仅使用快捷键开关与退出入口。

---

## 一、权限与启动

初次打开应用或进入「设置 → 通用 → 权限与启动」时，可根据状态指示完成授权：

- **辅助功能**：用于读取当前应用选区，以及执行输入框文本替换与自动滚动拼接。
- **屏幕录制**：用于区域截图、窗口/应用录制、长截图、实时区域翻译与本地 OCR。
- **开机自启**：可在设置页直接切换是否随系统登录自动启动。

授权后如状态未立即刷新，点击状态旁操作即可跳转对应系统设置页面或重新校验。

## 二、全局选区翻译

### 1. 唤起方式
- **划词触发按钮**：启用「全局自动取词」后，在任意应用选中文本，选区附近会出现紧凑的触发按钮（默认约 84×30pt），点击即可翻译，不抢占来源窗口焦点。
- **快捷键直接翻译**：开启「仅使用快捷键」或在菜单栏切换该模式后，不弹出划词按钮，直接按快捷键（默认 `⌘⇧T`）翻译当前选区；若光标或选区位于可编辑输入框内，按替换快捷键（默认 `⌘⇧R`）则以输入直译气泡展示结果。
- **独立文本上下文判断**：非文本选区（例如在访达选中文件、空白处点击、仅按修饰键或拖动滑块）不会误触发，应用本身与「排除应用」列表内的窗口也会跳过。

### 2. 翻译卡片与模式切换
- **顶部栏**：支持一键切换四种文本处理模式——**翻译**、**润色**、**纠错**、**解释**；右上角可针对当前卡片临时切换翻译服务（仅作用于本张卡片，不修改全局默认配置）。
- **三种卡片布局**：
  - **单栏紧凑布局**：显示译文，并在开启对应选项时展示原文（译文在上、原文在下，总高随内容自适应）。
  - **双语对照布局**（`720×420`）：左栏译文、右栏原文并排对照。
  - **单词词典布局**（`720×420`）：左侧展示单词音标、词性释义与例句，右侧展示补充翻译结果。
- **悬停与底部操作栏**：鼠标悬停卡片时显示底部操作栏，并在对应文本栏位展示朗读与复制按钮，常用操作包括：
  - 固定/取消固定浮层（拖动可调整位置，按 `Esc` 或外部点击收起非固定浮层）
  - 原地替换来源选中文本（可编辑上下文中可用）
  - 语音朗读与停止（再次点击同一栏朗读按钮立即停止）
  - 复制原文 / 复制结果 / 加入生词本（查到词典释义并翻译完成后可用）

### 3. 输入直译与替换
在可编辑输入框中选中文本后按下 `⌘⇧R`：
1. 在输入光标或选区旁弹出轻气泡显示直译结果（带重试与取消）。
2. 按 `Enter` 或点击确认，通过系统辅助功能与剪贴板原地替换来源输入内容；替换完成后保留译文历史，不打断原应用输入状态。

## 三、翻译历史、生词本与截图历史

通过菜单栏点击「翻译历史」可打开统一的历史管理窗口，顶部提供三个分段切换：

### 1. 翻译历史
- **记录开关**：窗口右上角提供独立的「记录」开关，关闭时仅暂停写入新记录，不影响已有数据的查询与删除。
- **筛选与搜索**：支持关键字实时检索、语言方向筛选与结果状态筛选。
- **分组与卡片展示**：按日期悬浮标题分组（同一组共用一张圆角卡片），每条记录采用**译文在上、原文在下**排列；悬停条目右下角可快速语音朗读、复制译文或删除单条记录。
- **保留策略与清空**：支持按保留天数自动清理旧记录（确认弹窗会预先显示将清理的条数），也支持一键清空全部记录。

### 2. 生词本
- 收录从翻译卡片加入的单词、音标、词典释义与译文。
- 支持搜索、按字母或日期查看、朗读、复制与导出为 CSV / Markdown 文件。

### 3. 截图历史
- 保留已保存或主动「保留在历史」的截图记录（保存目录默认位于 `~/Library/Application Support/TranSnap/` 下按模块与日期组织）。
- 每条记录支持直接**打开编辑**、**复制**、**在访达中显示**与**删除**。
- **多图处理**：勾选 2 张及以上截图可进行横向/纵向**拼接**；勾选 1 张（高度 ≥ 2px）可进行纵向/横向**拆分**；勾选 2 张可进行逐像素差异**比较**（并排预览与差异蒙版）。

## 四、屏幕采集与编辑

按下截图快捷键（默认 `⌘⇧S`）或从菜单栏点击「区域截图」，冻结当前屏幕并进入全屏选区编辑模式。

### 1. 选区与窗口定位
- **快速框选与智能窗口吸附**：鼠标点击可命中下层窗口边界；拖动框选期间选区四周持续显示八向控制点、维度尺寸胶囊与动态对齐辅助线。
- **快捷键微调与关闭**：方向键（配合 `⇧`/`⌥`）可像素级调整选区与文本框位置；`Esc` 取消当前操作。

### 2. 工具栏与自定义快捷键网格
- **分组与角标**：主工具栏按修饰键分组（默认含无修饰、`⌘`、`⌥` 三组），每组 6 格对应物理数字键 `1–6`。有修饰键的分组头部显示对应符号（无修饰组不显示前缀标签），工具按钮右上角按需展示 `1–6` 角标。
- **默认父子结构**：「截图」下默认挂接「录制」与「滚动长截图」，点击可展开统一风格的二级托盘；选择标注工具或美化/比例等属性时，在工具栏内依次展开二级属性与三级附加行。
- **编辑与辅助工具**：
  - 基础编辑：光标选择（命中文本框或标注框旋转/缩放控制点）、矩形/椭圆/箭头/直线、画笔/荧光笔/马赛克（支持实心渐变填充与调色盘）、序号标记、文字输入框、自定义贴纸、渐变美化背景（含阴影与圆角导出）。
  - 辅助能力：实时像素取色器（点击复制 `#RRGGBB`）、像素标尺、桌面置顶**贴图**（支持多张独立置顶、拖动与缩放，`Esc` 仅关闭当前选中贴图）。
  - 文字与条码：**识别文字**在原地执行离线 Vision 文档 OCR（保留标题、段落、列表与表格 Markdown 结构），同时并行解码画面中的二维码与条码并支持一键复制或打开 HTTP/HTTPS 链接；**翻译文字**将识别到的段落块直接贴合覆盖在截图之上，支持单独隐藏原文。

### 3. 屏幕录制与长截图
- **录制**：展开录制附加行选择录制目标（选区 / 窗口 / 应用，选中应用时会合并该应用在全部屏幕的可见窗口到统一黑底画布）与延时倒计时。开始后屏幕四周显示采集状态光带与悬浮四气泡控制条（暂停/继续、停止、放弃与计时）；区域与全屏录制还支持光学点击特效与拖动轨迹高亮。
- **长截图**：支持手动滚动（自动按固定顶底边带与位移对齐拼接）与辅助功能自动滚屏。过程中出现轻量缩略预览窗，点击停止后进入统一结果窗。
- **实时区域翻译**：选择实时翻译并框选目标后，持续以未编码屏幕帧增量 OCR 并把译文直接叠加渲染于选区上方，窗口本身保持穿透不遮挡正常操作。

### 4. 统一结果窗
录制视频、长截图与通过系统「打开方式」导入的本地图片共用同一套结果窗口骨架：
- 媒体画布四周保持 `24pt` 中性衬底留白，底部固定 `52pt` 操作栏，左/右各功能组以细分割线隔开。
- 窗口标题格式为：`录制 · m:ss · 宽 × 高`、`长截图 · 宽 × 高` 或 `图片 · 宽 × 高`。
- **录制结果窗**（最小 `600×200`）：原生无自带控件播放器 + 自定义进度条、起止帧时间裁剪、导出格式选择（**MP4** / **GIF** / **APNG** / **WebM**）、复制与保存。
- **长截图结果窗**（最小 `600×240`）：支持「适合宽度」与「实际大小」一键切换，提供重拍、复制与保存。
- **打开本地图片**（最小 `600×240`）：保留全部绘图、贴纸、渐变美化、OCR 与图内翻译功能，屏蔽屏幕选区裁剪与贴图采集操作。

## 五、设置窗口导航

设置窗口左侧为两级固定侧边栏，所有改动自动串行校验保存：

| 一级分组 | 二级子页 | 主要配置内容 |
| --- | --- | --- |
| **通用** | **权限与启动** | 辅助功能与屏幕录制授权状态与一键引导、开机自启开关 |
| **通用** | **个性化** | 浅色 / 深色 / 跟随系统外观、系统与自定义强调色、前景色与窗口透明度调节 |
| **翻译** | **语言与服务** | 默认源/目标语言、翻译/润色/纠错/解释四模式默认服务、自动划词与展示选项 |
| **翻译** | **服务列表** | 管理系统/网页免配置服务、OpenAI 兼容及第三方 API 服务、连通测试、默认提示词与术语表 |
| **翻译** | **快捷键** | 录制全局选区翻译、输入替换与区域截图快捷键，自动避让系统/工具栏冲突 |
| **翻译** | **排除应用** | 添加不触发全局划词的应用白名单/排除列表 |
| **截图** | **保存与导出** | 默认保存目录、确认截图默认动作（保存/复制/贴图等）、截图历史留存策略 |
| **截图** | **录制** | 视频与动图默认格式（MP4/GIF/APNG/WebM）、GIF 帧率与最大宽度、录制倒计时与点击特效 |
| **截图** | **操作** | 框选/窗口识别行为、取色颜色格式与标尺单位等交互习惯 |
| **截图** | **贴纸** | 管理本地贴纸图片集与默认贴纸尺寸 |
| **截图** | **工具栏** | 拖拽重排 `1–6` 格位按钮、添加/编辑最多 8 组修饰键分组、设置父子挂接与显隐、检测系统快捷键冲突 |
| **MCP** | — | 开启「允许 agent 截图」与「允许操控电脑」、复制客户端 JSON 配置、一键安装到兼容客户端 |

## 六、接入本机 MCP 客户端

TranSnap 随应用携带独立签名校验的 stdio MCP helper：`/Applications/TranSnap.app/Contents/MacOS/transnap-mcp`。

1. 在「设置 → MCP」打开 **允许 agent 截图**；如需让模型代点屏幕或键入文本，按需打开 **允许操控电脑**。
2. 点击 **复制客户端配置**，或直接在「接入平台」卡片点击对应客户端（Claude Code、Claude 桌面、Codex、Grok）的 **安装**：
   - 命令行类客户端通过其官方 CLI 自动注册 `transnap` MCP 服务。
   - Claude 桌面会自动备份并更新 `claude_desktop_config.json` 下的 `mcpServers.transnap`。
3. 如移动了 App 位置导致页面提示「路径已变化」，点击 **重新安装** 即可刷新配置；模型首次操控受保护应用时，系统会弹出一次授权确认卡片。

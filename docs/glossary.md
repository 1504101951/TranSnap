# TranSnap 领域术语表

本表定义 **TranSnap** 全项目通用的核心业务概念，代码命名、界面文案与规格文档保持同一套术语。

---

## 核心概念对照

| 术语 | 定义 | 对应界面 / 代码边界 |
| --- | --- | --- |
| **划词翻译** | 在任意应用中通过鼠标拖拽、双击/三击等手势选中文本触发的翻译入口 | 显示接近文本末尾的触发按钮（约 84×30pt），点击后再展开翻译卡片 |
| **快捷键翻译** | 启用「仅使用快捷键」或直接按下默认 `⌘⇧T` 对当前选区执行的翻译流程 | 不显示划词触发按钮，直接生成非激活译文浮层 |
| **输入替换** | 在可编辑输入框中选中文本并按下 `⌘⇧R`，于光标附近弹出直译气泡并支持 `Enter` 原地替换原文 | 由 `AccessibilitySelection` 读写来源焦点的可编辑内容 |
| **排除应用** | 用户在「设置 → 翻译 → 排除应用」中添加的应用程序黑名单 | 这些应用内的鼠标选区与按键不触发自动取词 |
| **翻译卡片 / 浮层** | 展示翻译、润色、纠错或解释结果的非激活悬浮窗口（`TranslationOverlay`） | 不抢占来源应用焦点；支持单栏（`560` 宽）、双语对照（`720×420`）与单词词典布局 |
| **双语对照** | 翻译结果与原文并排或上下同时呈现的阅读视图 | 宽卡对照模式下左栏显示结果、右栏显示原文；单栏紧凑模式下上栏译文、下栏原文 |
| **单词词典** | 当选中内容识别为单个词汇且具备词典数据时自动启用的对照视图 | 左栏显示音标、词性释义与例句，右栏展示翻译服务译文，支持一键加入生词本 |
| **翻译记录 / 历史** | 保存在本地 SQLite 的选区翻译与输入替换历史（可按「记录」开关启停） | 位于历史窗口「翻译历史」分段，按日期悬浮标题与圆角卡片分组 |
| **生词本** | 从翻译卡片收藏的词汇表，包含音标、释义、译文与创建时间 | 位于历史窗口「生词本」分段，支持检索、朗读与 CSV/MD 导出 |
| **截图工具栏** | 全屏区域截图时跟随选区或退让显示的可配置动作栏与多级托盘 | 主行由 6 格/组、物理键 `1–6` 映射构成；动态次级工具通过 `LiquidSplit` 托盘展开 |
| **统一结果窗** | 录制视频、滚动长截图与系统「打开方式」图片共用的审阅与导出窗口 | 采用 `24pt` 媒体留白画布 + 底部 `52pt` 固定操作栏（最小 `600×200` / `600×240`） |
| **贴图（Pin）** | 将当前选区截图或剪贴板图片转为独立悬浮置顶窗口的功能 | 独立非激活面板，支持多窗同时存在、各自拖拽与按 `Esc` 关闭选中贴图 |
| **截图历史** | 对主动保存或选择「保留在历史」的截图建立的本地归档列表 | 支持重新打开编辑、拼接（≥2张）、拆分与逐像素比较（2张） |
| **实时区域翻译** | 在屏幕划定区域或指定窗口后，持续跟踪画面文字并将译文直接覆盖叠加于选区上的模式 | 由 `LiveRegionCapture` 与 `LiveRegionCoordinator` 驱动，盖层点击穿透不阻塞底层交互 |
| **本地 MCP 服务** | 遵循 MCP stdio 协议随 App 附带的本地助手接口（`transnap-mcp`） | 连接本机运行中的 TranSnap 主进程，按授权开关提供截图、OCR 与界面操控能力 |

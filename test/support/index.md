# test/support 目录索引

测试共用的夹具工具。

1. [capture_pixels.dart](capture_pixels.dart)：把测试 PNG 解码为源图或转换为截图快照的 BGRA 原始像素字段，并等待截图引擎建好源图。
2. [settings_pages.dart](settings_pages.dart)：提供设置窗口侧边栏行的查找、子页内容滚动列表的查找与点选切换子页的测试工具。
3. [line_icons.dart](line_icons.dart)：按代码里的常规字重 Lucide 图标查找按尺寸换字重渲染的 LineIcon。
4. [index.md](index.md)：索引本目录直接子文件的用途。
5. [fonts/](fonts/index.md)：字体下载测试使用的真实字体文件及其许可证。

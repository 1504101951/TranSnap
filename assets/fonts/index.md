# assets/fonts目录索引

内置字体组合「中性」的字体文件、各组合的名称子集字体与许可证。

1. [Inter.ttf](Inter.ttf)：「中性」组合的西文字体（可变字重）。
2. [NotoSansSC.ttf](NotoSansSC.ttf)：思源黑体，「中性」及多数组合的中文字体（可变字重）。
3. [names/](names/index.md)：只含字体菜单文字的名称子集字体，未下载的组合也按自身字体显示名称。
4. [licenses/](licenses/index.md)：各字体的版权声明与许可证全文。
5. [index.md](index.md)：索引本目录直接子文件和子目录的用途。
